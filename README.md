# DADA Downloader (Static Demo)

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser, or deploy the folder to GitHub Pages / Netlify / Vercel as a static site.

## What works
- Responsive paste-link interface.
- Clipboard paste (browser permission required).
- URL validation.
- Opens direct `.mp4` URLs so the browser can play/save them.

## Important limitation
This is a front-end-only static website. It cannot extract video files from Instagram, Facebook, YouTube, or other social-media page URLs. Those platforms do not expose the underlying media file to a static browser page. To support permitted public media downloads, add a backend that uses an authorized API/provider and respects platform terms, copyright, privacy, and access controls. Never attempt to bypass private-account restrictions or DRM.

No API keys, database, or backend are included.
